## 研究为什么仍未完成

本轮已完成一次真实 API 批量：53 个目标分别运行只读源码、相似案例和漏洞／修复配对三种策略，159 次正式请求得到 158 个有效模型结果、1 个格式校验失败。52 个共同有效目标的 F1 分别为 0.9792、0.9684、0.9787；163 条新候选得到 83 条支持、0 条反驳、80 条未知。详见 [真实采集报告](releases/R2-20261010/experiments/2026-10-14_SYNAPSE_REAL_API_REPORT.md)。

含两个冒烟共 161 次请求尝试，零自动重试；一个冒烟失败且用量未知。源码保持一致，但共享目录两次重新构建 JAR，采集跨三个构建产物阶段，两个 class 文件差异原因尚未核实。焦点和模板尚未进入模型提示，本批不能评价它们的发现增益。完整请求、失败与身份限制均已分别保存。

RabbitHole 与 Atomic 的维护者修复前后，目前最终候选都还是未知。初始化、继承、回调和跨合约 token 状态超出现有完整证明范围，因此尚未得到预期的“漏洞有支持证据、修复有反驳证据”双向对照。

旧 133 条的未知数量目标未达到，独立候选真值与精确 token 公平也尚未核实。整体工程记录为部分完成（PARTIAL），研究效果为尚未验证（UNVERIFIED）。模型发现成绩另见 [实验看板](releases/R2-20261010/attachments/EXPERIMENT_DASHBOARD.md)；本轮 D1 未超过只读源码对照，也仍未形成真实修复双向结论。
