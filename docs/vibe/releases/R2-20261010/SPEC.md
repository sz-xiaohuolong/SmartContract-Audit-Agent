## 状态与研究语义

工具成功只说明运行与解析成功。告警、空告警、guard 名称、模型意见一致或无假设不构成漏洞/安全证明。失败、超时、解析错误、绑定错误、事实不全分别留证；UNKNOWN 保持未知。反驳候选仅针对该候选，不推断整合约安全。

来源真值、自动标签、人工构造假设、合成夹具分开记录。无独立审核时 `researchEligible=false`，研究效果保持 UNVERIFIED。历史模型结果含答案标注风险，派生重放仅评价保存候选核验，不代表清理后模型发现实验。禁止靠扩大弃权、放宽完整性或把未知算阴性来宣称增益。

默认新增付费请求预算为 0。完成 D1 离线检查及可审查的正式实验方案；需要真实模型时另行提出模型、端点、输入/输出额度与总费用的具体方案。付费授权和独立审核的缺失不阻止其他工程工作，不伪装成研究已验证。
