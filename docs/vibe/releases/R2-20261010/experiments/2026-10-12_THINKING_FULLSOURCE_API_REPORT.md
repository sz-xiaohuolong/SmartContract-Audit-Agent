## 每个样本是否真的请求了 API

正式批次 `samples.jsonl` 有 159 条唯一目标／策略记录，`events.jsonl` 有对应启动事件；每条 `requestAttempts=1`，没有零请求或次数缺失单元。159 条请求记录的 `inputTokens` 与 `outputTokens` 均为整数，合计分别为 **297,128** 与 **119,672** token。最大单次输入为 10,762 token；未观察到完成 token 触顶。53 个目标的源码摘要、标签、供应商和快照均与上一批计划一致。Java CLI 仍保留 1 MiB 文件读取安全上限，本批最大源码仅 36,386 字节，没有触及它。

上一批被阻断的 6 个目标本次各有 3 次请求，18 个模型结果全部有效。其中最长的 Spank Chain Payment 清理源码为 36,386 UTF-8 字节；其三个策略累计输入 31,507 token，说明该样本已进入真实模型调用。Java 入口还校验传入的全文源码与 SHA-256 摘要一致。模型输入没有本地截短；但本机 Nomic 查询嵌入有独立的 8192 上下文限制，**3 个长目标的查询向量在 9 个策略单元中记录了截取**。Dense／D1 的检索上下文另保持 4096 字节上限。这两个检索限制不应与 DeepSeek 收到的完整源码混为一谈，也限制了本次检索对照的解释范围。
