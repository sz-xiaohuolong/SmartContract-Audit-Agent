## D2事实ID接缝与零模型诊断

发现阶段的编译目录与候选阶段分别创建编译收据，而事实ID包含绑定收据的环境摘要。即使源码、AST节点和字节跨度完全相同，新目录候选的riskFactId也无法匹配候选阶段的事实ID，引擎按RISK_BINDING_MISMATCH拒绝。该问题已在SimpleDAO实际收据上定位，详细身份对照见本轮`risk-binding-diagnostic.json`；未放宽ID、行号或保护判据，也没有改写候选。

零模型诊断复用同一真实发现编译收据，重新执行Slither及D2，SimpleDAO原候选由UNKNOWN得到SUPPORTED，工具状态OK，候选保持原字节。这是独立诊断原件`same-receipt-pilot.json`，没有并入本次冻结代码的正式结果，也不能代表接缝已在产品中修复。本批D2结果与以下逐候选统计仍按原执行记录报告。
