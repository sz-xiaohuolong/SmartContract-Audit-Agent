## Task Handoff Contract 与测试接缝

所有代码任务 **REQUIRED SUB-SKILL:** Use superpowers:test-driven-development；先观察有意义失败，再最小实现和回归。技能不可调用时使用同等原生红绿循环。批准范围为 SPEC，本计划的普通实现细节已受用户授权，无需再次问内部命名或文件拆分。

环境任务拥有 Java `ToolAnalyzer/ToolCli` 及其测试、新 `tool_environment.py` 及其测试。输入任务拥有 `benchmark_targets.py`、`benchmark_runtime.py`、新评测清理模块及相关测试；不同时修改 `audit_run.py`。主代理串行整合工具调用、重放与文档。来源任务开始只读，不改变正式知识或标签。共享编排、数据契约与状态串行修改；任务合并后独立审查并完成系统验证。

环境接缝：注入本地编译器目录和可执行子进程；约束交集、精确版本、无匹配、失败分类、真实摘要、诊断脱敏与缓存变化。Java 保留旧 analyze 调用兼容，新可选编译器参数由固定配置提供。

输入接缝：真实词法保护字符串，清理注释答案而保持行数；改变 groundTruth/vulnerableLines 不能影响发现输入、选函数或风险；给定候选模式显式标注，旧批次保留。模型请求和查询使用相同清理输入。

重放接缝：读取原 samples.jsonl，不调用模型；工具结果按目标/config 缓存；原件前后 SHA-256 一致；结果关联原批次、原假设、代码与新配置；工具故障不改变模型原判断。

事实/路径接缝：使用真实编译器输出验证节点/行号/状态资源；同一保护的主体、资源、状态版本、执行顺序和入口覆盖改变时结果随证据变化。既有 39 项 D2 保守回归继续有效。
