# 合规与运行审计规范

本附录供复现实验、维护运行环境和追查历史身份时查阅。系统概念与实验结论分别在技术设计和实验看板说明；这里集中保存会打断初次阅读的运行细节。

## 凭证与模型调用

凭证来自环境变量或 Git 忽略的 `config/providers.local.properties`。捕获的配置仅在内存和权限为 600 的临时文件中消费，执行结束清理；日志与报告保存摘要及脱敏诊断。真实密钥、原始供应商配置和包含密钥的终端输出不得进入 Git。

真实模型调用需要显式选择配置与具体运行范围。一次批量采集、一次历史重放和一次本机演练是不同操作；已有历史调用登记不能自动解释为再次调用的许可。本文档重构只读取已有研究材料，不请求模型或生成嵌入。

模型用量字段 `usage` 缺失表示无法知道实际用量，数据层保留 `null`，界面解释为未知；有部分观察量时仅报告已观察小计。没有可靠账单与价格映射时，费用金额保持未核实。请求数、token 数与套餐额度分别统计。

## 运行计划、锁与中断

工作台先固定源码、范围、知识池、上下文与配置摘要，再生成运行票据。执行前重新核对计划，变化时重新预览。Python 的单写者锁避免同一服务同时写入运行材料；本机服务默认只接受回环地址请求。

运行阶段和失败都保存事件。服务重启后未完成运行显示 `INTERRUPTED`（已中断），不会自动重发模型。历史摘要校验失败则拒绝回放；新报告使用 `schemaVersion=2`，旧报告只读。

## 证据怎样证明属于这次分析

编译收据绑定源码及全部依赖、版本、二进制、设置和产物。独立 Slither 收据另行核对同一程序。候选的事实 ID、合约投影、风险跨度和最终输出要能回查这些收据。保存候选重新核验时，实际使用的编译清单独立写入报告。

派生重放生成新目录，保留原候选、原模型响应、用量与标签。模型发现输入变化时建立新计划；不能用新源码续写旧实验。代码提交号用于定位版本，实际执行还可能含本机修改，因此同时保存源码文件、JAR 和工具的摘要。

六项保护卡片和最终漏洞候选分别记录对象。保护被反证说明保护失效，不能自动算作漏洞候选被反驳。侧复核的 `PASS/CONFLICT/UNRESOLVED` 只表示对应核查结果，当前 `gateApplied=false`，不改写 D2 的三态结论。

## 原件位置与保存预算

| 材料 | 位置与用途 |
|---|---|
| 原始模型批次 | `research-artifacts/runs/benchmarks/`，保存计划、事件、样本与响应 |
| 派生核验 | `research-artifacts/runs/derived/`，保存重放与四臂结果 |
| 编译、Slither、EVM 收据 | `research-artifacts/receipts/`，核对输入、环境与程序执行 |
| 数据、标签、来源与固定候选 | `data/` 及根目录原始数据集，作为运行输入和登记 |
| 本机环境与恢复材料 | `.local/`，不与研究结果混放 |
| 关键验证材料 | `.evidence/<release-id>/<task-id>/`，保留必要日志、摘要和截图 |

原件分类以 [research-artifacts/README](../../../../../research-artifacts/README.md) 为准。部分材料默认 Git 忽略，尚未配置远程备份；Git 忽略只说明不提交，不能证明已经备份。

证据默认预算为单文件 1 MiB、单任务 10 MiB、整个 `.evidence/` 100 MiB。超过预算先核对引用与唯一性，再去重或 gzip 无损压缩；保留关键失败与修复对照。模型原文、候选、错误、用量和证明原件不能截断。`storage.read_artifact()` 读取压缩材料并验证原始 SHA-256。

不长期保存 JAR、class、虚拟环境、模型权重或数据集副本作为验证证据。用构建命令、Git 版本与产物摘要记录可再生成产物；清理结束检查读取入口和保留原件。具体规则见 [AGENTS](../../../../../AGENTS.md#证据保留与本地空间管理)。

## 构建、报告与只读复核

根构建：`mvn clean verify`。Python：`PYTHONPATH=tools/experiment python3 -m unittest discover -s tools/experiment/tests -v`。CLI：`java -jar audit-mvp/target/audit-mvp-0.1.0-SNAPSHOT.jar --help`。

`benchmark_report.py` 从保存结果生成统计，不调用模型或静态工具。`tool_replay.py --compiled` 会执行本机工具并写新派生目录，但不请求模型。不要把这两种复核操作混为一谈。完整命令沿用对应原报告与 [工具说明](../../../../../tools/experiment/README.md)。

历史别名 `.local/auto-benchmark-runs/` 等可通过迁移兼容入口定位同一权威原件。新机器需要另外恢复历史材料和工具二进制；原始 SHA-256、收据与源文件应共同核对。
