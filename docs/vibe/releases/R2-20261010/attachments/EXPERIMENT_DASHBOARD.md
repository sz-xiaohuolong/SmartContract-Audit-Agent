# 实验现状看板：成绩、覆盖和仍待回答的问题

目前可以展示模型发现和候选核验的探索性结果。D1 在不同批次上的表现有升有降；D2 对部分保存候选给出了支持证据，但真实维护者修复对照与未知数量目标仍未完成。因此，工程是部分完成（PARTIAL），总体研究效果尚未验证（UNVERIFIED）。

## 先分清两种成绩

模型发现的 F1 回答“模型报告与数据集标签符合到什么程度”。F1 综合精确率与召回率；精确率看报告里有多少判断正确，召回率看标注问题有多少被找到。当前表格按目标级 REPORT／NO_REPORT 统计，尚未使用独立审核的候选真值。

D2 未知率回答“保存的具体猜想中，有多少暂时缺少充分核验证据”。它的分母是候选数量。一份合约可以产生多条候选，同一目标也会分别运行三个策略，因此候选条数不能当作独立合约数。

## 三策略的模型发现 F1

每行只比较该批次中三策略均有有效模型判断的同一组目标。不同批次的共同目标数量、输入资格、提示和模型设置可能不同；下面是各自的实验成绩，不是单因素消融结果。

| 采集批次 | 共同有效目标 | Vanilla F1 | Dense F1 | D1 F1 | 对应原报告 |
|---|---:|---:|---:|---:|---|
| 2026-10-11 首次 R2 采集 | 45 | 0.8056 | 0.7887 | 0.7536 | [原报告](../experiments/2026-10-11_API_BATCH_REPORT.md) |
| 2026-10-12 第二次采集 | 45 | 0.8219 | 0.8684 | 0.9383 | [复验](../experiments/2026-10-12_API_REVALIDATION_REPORT.md) |
| 2026-10-12 AST 升级后 | 46 | 0.9000 | 0.9136 | 0.8718 | [AST 复验](../experiments/2026-10-12_AST_API_REVALIDATION_REPORT.md) |
| 2026-10-12 思考模式与完整源码 | 51 | 0.9783 | 1.0000 | 0.9783 | [全文复验](../experiments/2026-10-12_THINKING_FULLSOURCE_API_REPORT.md) |
| 2026-10-13 阶段升级后 | 51 | 0.9892 | 1.0000 | 0.9783 | [新采集](../experiments/2026-10-13_STAGE1_5_REAL_API_REPORT.md) |

第二次采集的 D1 高于该批对照；后两次共同目标中 Dense 更高。负例只有少量数据集对照，知识标签也有自动标注限制，现有结果尚不足以声称 D1 普遍优于 Dense。

## 为什么还不能写“研究目标完成”

| 待解决的问题 | 当前事实 | 对论文的影响 |
|---|---|---|
| 真实修复是否能被识别 | RabbitHole 与 Atomic 修复前后最终均未知 | 尚未展示访问控制／重入各一组“真实漏洞被支持、维护者修复被反驳”的完整对照 |
| 未知数量是否达标 | 旧 133 条仍有 58 条未知 | 保留未达目标的结果，继续解释覆盖缺口 |
| 标签是否独立可靠 | 10 个事件已盘点，6 个正式事件的 18 份原件齐全；独立候选审核尚缺 | 数据来源标签不能代替每条候选的独立真值 |
| 模型预算是否公平 | 已保存上下文字节与预算组成，精确 tokenizer 未核实 | 不能把相同字节上限称作等 token 对照 |
| 是否完成机制消融 | 焦点、模板与独立复核已实现展示或侧报告 | 尚不能把工程接入归因于模型发现效果提升 |
| 是否能跨机器复现全部历史 | 原件与固定工具远程备份未配置 | Git 仓库包含源码与夹具，完整历史身份仍依赖本机材料 |

当前有限执行证明的是特定属性与初态下的反例，尚未给出普遍的漏洞可利用性证明。严谨表述可以是“实现了可追溯审计流程，并观察到保存候选核验覆盖增加”；“显著降低误报”“普遍优于基线”等主张需要进一步实验。

## 怎样复核这些表

先从每行原报告确定目标分母，再读取保存的 `plan.json`、`events.jsonl` 和 `samples.jsonl` 重算。固定候选重放还需核对 `manifest.json` 和输出摘要。失败、无有效输出及候选未知分别统计，避免把它们填成正确负例。

命令与本机恢复材料见 [合规与运行审计规范](OPERATIONS_AND_REPRODUCIBILITY.md)。本页只汇总已经存在的记录；2026-10-14 另行登记的待采集计划尚无此处可引用的新采集报告。
