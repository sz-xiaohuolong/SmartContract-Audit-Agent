# 本机环境与研究原件整理

2026-10-12 开始，2026-10-13 完成收尾验证，按用户要求拆分 `.local/`、收紧证据保留规则并释放本地空间。本次原地移动 33 个现存目录，无损归档 6,248 份文件，净减少文件内容 **704,518,776 字节，约 672 MiB**。目录移动不计为空间释放；模型响应、候选、标签、计划及统计保持原值。新增模型请求为 0，R2 研究验证仍为 UNVERIFIED。

## 为什么原来超过 2 GiB

`.local` 原先混放环境、依赖、向量服务数据、外部仓库、实验结果和恢复材料。隐藏目录与 Git 忽略只控制展示和版本管理，不能说明内容可删除，也不提供备份。

30 个模型批次的三类主要文件约 334 MiB：

| 文件 | 原始字节 | 原因 |
| --- | ---: | --- |
| `samples.jsonl` | 147,912,802 | 每单元包含检索、模型、工具和 D2 明细 |
| `summary.json` | 147,136,505 | 历史摘要重复保存全部样本 |
| `samples.csv` | 55,364,949 | 预生成完整导出，重复嵌入明细 |

逐样本字段累计编码中，检索约 91.5 MiB、工具约 29.6 MiB、D2 约 14.5 MiB、源码约 1.6 MiB，模型字段约 1.3 MiB。字段统计采用规范 JSON 编码，并非磁盘精确分摊。主要体积来自重复记录和程序复核所需的机器明细；可读 Markdown 报告是原件的摘要。

## 目录职责

| 入口 | 当前职责 | 整理后占用约值 |
| --- | --- | ---: |
| `.local/` | Python 环境、模型、Milvus、固定 solc／依赖及唯一恢复材料 | 1.31 GiB |
| `research-artifacts/` | 真实批次、派生结果、知识快照、固定历史输入和工具收据 | 195 MiB |
| `data/external/` | 下载的候选与对照仓库 | 198 MiB |

`.local` 主要占用为 Python 嵌入环境约 877 MiB、Milvus 约 233 MiB、BGE 模型约 128 MiB、Solidity 环境约 101 MiB。本轮保留可用运行环境，仅减少重复存储与归档编码。

详细分类及恢复见[研究原件入口](../../../../research-artifacts/README.md)，全部映射见[目录映射](../../../../tools/experiment/verirag/infrastructure/artifact_layout.py)。迁移使用原地重命名，旧路径保留相对兼容链接，定位同一份原件；新写入默认使用规范目录。EVM 历史入口预留到规范收据目录，已有未提交实现未来写入也会落入该目录。

使用 agent-reach 技能的 GitHub／`gh` 后端读取 README、目录及忽略规则，比较实际工程组织方式：

| 工程与读取版本 | 已核实做法 | 采用的原则 |

这些工程支持职责分离，没有要求论文只保存 Markdown。AGENTS 的 1 MiB／10 MiB／100 MiB 证据预算是本项目约定。

## 一键整理与持续控制

```bash
python3 tools/experiment/organize_storage.py --apply --restart-ui
```

项目根目录执行，省略 `--apply` 只预览。整理器核对进程与写锁、拒绝目标冲突、重命名后校验目录字节；归档解压校验通过后才删除源编码。未完成批次保留可续写原件。大型封口 JSONL、历史重复汇总、CSV、编译／工具 JSON 和快照采用 gzip，读取、重放及下载支持透明解压。

新摘要只保存统计、计划及原件指针，完整样本只存一份；CSV 按请求导出。压缩批次经续跑入口只读返回，不新增模型请求，也不覆写历史归档摘要。冲突、压缩损坏和读取超限均报错，失败和缺失状态保持 UNKNOWN／null。

## 验证与证据

本机证据为 `.evidence/R2-20261010/storage-layout-20261012/`；迁移清单及迁移前基线在 `research-artifacts/migrations/`，默认 Git 忽略。

| 检查 | 实际结果 |
| --- | --- |
| 原件完整性 | 15,040 份登记文件逐份还原读取，原始 SHA-256 全部一致 |
| 模型批次 | 30 批次全部非样本字段、样本规范摘要、指标、候选及 D2 明细一致 |
| 派生结果 | 3 个封口报告规范摘要一致，原批次仍可得 |
| 快照／编译 | 6 个 BGE／Nomic 快照完整性通过；6 份编译清单通过固定 solc 重编译与输出核对 |
| 本机接口 | 8 个只读 HTTP 检查通过：运行状态、新旧正式批次 JSONL／CSV、3 个派生 JSONL；下载与原字节一致 |
| 回归 | 工作区全量 Python 677 项、存储专项 10 项通过；独立提交内容全量 650 项通过，网关 1 项在构建后补验通过；Maven 97 项及 CLI 帮助通过 |
| 幂等 | 再次执行未移动或压缩既有原件；首次补齐未来 EVM 入口，最终迁移／归档／新增兼容入口均为 0 |

`integrity.json` 保存具体摘要与下载路由；`verify_integrity.py` 可用 `PYTHONPATH=tools/experiment` 只读复核。两次实际归档记录分别为 1,265／4,983 文件、577,858,755／126,660,021 字节净释放。验证临时副本收尾清理，不长期留在证据中。

## 恢复与限制

配置、来源登记、固定候选、夹具和历史文档继续版本控制，现有其他未提交开发内容保留。gzip 只改变存储编码，原逻辑文件名和还原字节不变。跨机器恢复需要复制研究原件及固定输入，运行整理器恢复兼容入口，再校验清单摘要。

研究原件目前只有本机归档，远程备份未配置；Git 推送包含规则、工具、测试和可读报告，不含被忽略原件。本次证据证明本机迁移与读取完整性，尚不提供跨机器长期归档证明。历史 Java 复核输入、关键截图、编译调查与工具输出仍有单文件超限例外，按原[保留登记](../../../../.evidence/R2-20261010/evidence-retention-20261012/README.md)维护；当前全体证据低于 100 MiB 预算。
