# R1-S3 本地可视化验收台

日期：2026-09-24。用户明确要求实施下一个可视化小步骤并启动项目前后端。本页是本机实验操作入口，不改变 S3 真实数据 G1 未通过和 D1/D2 效果未验证的结论。

## 本次范围

- 一个本地页面展示固定合成目标源码、两条知识案例、七种策略的排序、Recall@2、nDCG@2、互补证据和完整提示的合成计数预算。
- 点击「重新运行离线对照」时，后端用固定仓库夹具调用已有 `s3_pilot.py`、Java 检索 JAR 和程序事实脚本，逐次保存结果；历史结果可直接打开，不再次运行。
- 页面明确标识合成样本、研究合格数 0、计数器并非真实模型 tokenizer。服务只监听 `127.0.0.1`，固定输入路径，不接受任意源码、配置或供应商参数，也不读取本地密钥文件。
- 当前前端为原生 HTML/CSS/JavaScript，后端为 Python 标准库 HTTP 服务。前后端由同一个本地进程提供，不需额外安装 Node 依赖。页面是研究工作台，使用简洁的数据布局，不按宣传页模板设计。

## 启动与验收

在项目根目录执行：

```bash
mvn clean verify
python3 tools/experiment/local_ui.py --port 8765
```

浏览器打开 `http://127.0.0.1:8765/`。首页可见 1 个合成目标、7 种策略、研究可用样本 0。点击运行按钮后应显示「已完成，结果保存在本机」，并新增一条可点击的运行记录；选择「D1 去掉互补选择」应只出现防御案例。历史结果存放于 `.local/experiment-ui/`，该目录被 Git 忽略。停止服务使用启动终端的 `Ctrl+C`。

本页面不提供真实模型调用；已填写的 API Key 不会被页面读取。要运行真实研究实验，仍须先通过来源与标签审核，并冻结真实模型的完整提示 token 计数方案及付费请求上限。锁定测试集保持封存。
