## 实现了哪些能力

- 保留 300 对、600 片段的原知识快照，另外生成 145 张可回读机制卡片；155 对未取得完整机制变化窗口而排除。卡片保存原件、可见事件、资源归属键与局限，全部标为未独立语义审核。卡片缺少的原始报告、补丁提交和许可字段保留为空，来源字节核对不替代语义审核。
- 代码向量、代码词法、函数名目的代理、行为词法分别搜索完整知识侧。词法检索采用 BM25，即按查询词匹配程度排序；目的代理只提取函数名，没有额外模型摘要。各路结果合并成完整代码对，按名次倒数之和融合，名次从 1 开始。
- 新的并集策略排除明确的资源归属键冲突；路径和状态版本缺失时保留未知。互补选择按固定规则奖励新增保护差异、惩罚重复差异，保存每一步回执。当前是资源键与可见事件层面的原型，尚未实现完整主体、资源、状态、路径与保护顺序联合语义建模。
- 代码与卡片表达固定同案例、同顺序和共同准入预算；向量与融合排序共享同一新并集。评估按历史案例计数，两侧片段身份另存。实际卡片正文必须与冻结原件重建结果一致，不能只凭相同片段 ID 借用人工标注。
- 卡片只指导模型提出待核验候选，不进入 D2 的证明依据。默认工作台继续使用原路径；本轮新增能力由显式 R3 实验入口选择。
