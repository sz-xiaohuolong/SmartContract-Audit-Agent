# R1-S5 真实案例与 D1 页面对照

状态：依据用户 2026-10-07 的明确要求实施。目标是让用户在本机页面对独立真实案例运行 D1 与非 D1 策略；实验可能证伪 D1，不能预设提升。

## 数据范围

- 继续只研究访问控制和重入。案例索引可来自已核验的 ASE 2025、SCRUBD、Code4rena 原始裁决及项目审计；索引标签本身不等于研究真值。首轮候选控制在 10～15 个项目事件内，只把原始源码、报告、实际修复版本和逐事件判断可固定的案例准入。
- 保留正式知识 `AC-ASE-030` Maia、`RE-ATOMIC-001` Atomic Loans；拟增知识 `AC-RABBIT-001` RabbitHole。保留独立验证 `AC-ASE-040` PoolTogether；拟增验证 `RE-JPEGD-001` JPEG’d、`RE-INFINITY-001` Infinity。新增条目须以固定文件摘要和外部裁决通过准入后才生效；未通过者保持待审。开发目标和历史演示运行不自动改成验证真值。
- 同项目、漏洞事件、补丁对、完全重复与近克隆必须同组。原版和修复版只用于对应漏洞路径的正反判断，不能宣称修复后整份合约安全。未审核的目标—案例适用性为 `UNKNOWN`，锁定测试集不打开。
- 新知识快照使用已固定的本地 BGE 模型离线编码；仅在全部文档、向量、谱系和 Milvus 集合读回完整后原子激活。旧快照保留可重放，失败时继续使用旧快照。

## 页面实验

- 页面列出准入的验证目标及其审计范围。每次点击只运行一个“目标 × 检索策略”；先支持 `DENSE`、`FIELD_FILTER`、`D1`，每种策略从相同快照与候选池选择上下文，模型、提示正文、工具和 D2 规则保持一致。历史运行显示策略、目标、模型状态、失败与未知、用量和报告路径。
- 默认完全离线。真实模式仅在本机页面显式点击后调用现有已配置模型，每次点击最多一次请求、零自动重试、输出上限 2048 token；页面在点击前显示端点、模型、范围和请求上限。批量付费运行须另行显示样本数 × 策略 × 重复 × 模型阶段 × 尝试次数的上界。
- 比较 D1 审计效果之前，须有独立审核的目标漏洞真值、目标—案例适用性与支持／反证判断、固定的真实 tokenizer 和完整聊天模板 token 预算。仅有 UTF-8 字节硬限制时，页面可以展示工程运行，但 `researchEligible=false`，不生成“D1 提升”结论。
- 报告逐样本持久化，重新打开历史结果不重复调用模型。调用失败、解析失败、超时、工具缺失和证据不足保留失败或 `UNKNOWN`；缺失 usage 保留 `null`。独立验证集不用于调参；真实补丁对、人工改造和合成样本分别报告。

## 验收

离线测试覆盖来源摘要、修复对、跨组隔离、快照激活失败、三策略同池、预算与单次模型调用、结果恢复及历史零调用。运行 `mvn clean verify` 与 `PYTHONPATH=tools/experiment python3 -m unittest discover -s tools/experiment/tests -v`。实际 Milvus 和页面冒烟单列记录，不充作研究效果证据。
