# phase 5 工程验收：对照问题、同池排序与可回放记录

本轮把 CF-RAG 优化计划中的离线工程设施落实为代码。系统现在能从已核实的编译事实生成对照问题，用同一批完整案例计算两种排序，并保存可重新核对的记录。用户已于 2026-10-21 授权实施，范围为统一计划的 P5-00—03；模型发现比较和多分支起草继续后置。

工程设施已通过夹具验证，但真实排序效果尚未验证（UNVERIFIED）。本机历史输入保留了 8 个目标、46 个操作，其中 13 个能构造结构有效的对照问题。固定 BGE 编码器的完整输入预检阻断了这 13 个比较单元：各自候选池中存在超过 512 token 的完整材料。因此没有执行向量推理，也没有产生真实排序成绩。本轮真实模型请求、外部嵌入服务请求均为 0。

## 先用一个例子说明改了什么

假设待审合约先向调用者付款，再扣减调用者余额。过去的相似度检索可能找到许多“同样有付款”的案例，却未必把扣余额的顺序放在前面。

新入口先从编译记录确认付款操作与同一个调用者余额写入，再构造两个问题：“余额写入是否在外部调用之后？”和“余额写入是否在外部调用之前？”入口、余额资源和回调前提保持一致，只改变顺序。访问控制则支持将检查主体 `msg.sender` 与 `tx.origin` 对照，其他绑定条件保持一致。

每一份历史材料始终包含改动前和改动后两侧。程序计算这份材料与原问题的相似度，再减去它与最相似对照问题的相似度。材料若对两种情况都很像，差值可能较小。这个分数只帮助选择参考材料，不证明漏洞成立，也不保证两个问题的真实答案不同。

## 技术与核心代码

| 要解决的问题 | 技术与实际实现 |
|---|---|
| 对照问题不能凭空编造 | [phase5_retrieval.py](../../../../tools/experiment/phase5_retrieval.py) 的 `build_queries` 只接受重新编译核对一致的闭包。抽象语法树（AST，即代码的结构化表示）用于绑定检查、操作和状态资源；标签、样本名称及伪造事实 ID 不进入接口 |
| 区分“像不像”和“能否区分情况” | 同文件 `score_pool` 归一化向量并计算余弦相似度，逐份材料保存原问题分、每条对照分与差值。负值保留；零向量、非有限数、错维度、错模型及截断均失败 |
| 比较时只改变排序依据 | `rank_pool` 让 `P5_RELEVANCE` 按原相似度排序，让 `P5_MARGIN` 按差值排序；共用机制／资源过滤、完整材料去重、最多两对与 4096 UTF-8 字节预算，同分按稳定配对 ID 排序 |
| 结果能复核且不能篡改来源 | [phase5_cli.py](../../../../tools/experiment/phase5_cli.py) 的 `verify_sources` 从历史原件重建输入；`validate_run` 从保存向量重新算分、排名和消费文本。逻辑路径限制在根目录内，拒绝符号链接越界；输出目录整体原子发布，禁止覆盖既有结果 |
| 模型与输入不能悄悄变化 | `local_encoder` 核对已登记权重摘要，只加载本机 BGE；完整 token 数在向量推理前计算。超过上限整体失败，不自动下载、更换模型或裁掉代码 |
| 缺审核不能出现成绩 | [eval_ragas.py](../../../../tools/experiment/eval_ragas.py) 的 `evaluate_phase5` 校验审核者实际看到的源码、问题与完整材料，要求独立人工身份、审核人及依据。未审核、未支持和失败均保留，指标为空 |

差值公式如下，其中 `e` 是同一份完整前后配对，`q` 是原问题，`q′` 是对照问题：

```text
originalScore(e) = cosine(q, e)
margin(e) = originalScore(e) - max(cosine(q′, e))
```

评价单位是一个完整配对，沿用原指标定义：前 k 项有用比例（P@k）、有用项在候选池内的召回比例、首个有用项的位置（MRR@k）、有用材料是否排在前面（nDCG@k）。全部相关性为零时，P@k 为 0，另外三项为空。它们都不是漏洞发现准确率。

## 如何复现与后续边界

操作命令与审核格式见[工具说明](../../../../tools/experiment/README.md#phase-5离线对照查询与同池重排)。复现输出须选择尚不存在的目录；原件已压缩时由存储读取入口还原并核对字节。回放只验证保存向量及排序的内部一致性；准备和比较时的来源重建另外核对原件身份，两者不能互相代替。

目前不能判断选材是否改善，更不能声称漏洞发现准确率提升。下一步研究需要独立查询与相关性审核，并先解决固定编码器装不下完整材料的问题；改变模型、材料表达或预算时须更新方案并重新冻结输入，不在本轮悄悄换模型。P5-04 仍受独立增益、预算准入及新调用授权约束，P5-05 继续后置。
