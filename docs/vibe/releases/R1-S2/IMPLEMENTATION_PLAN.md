## 内部实现选择

案例使用显式角色条件（检查在风险前、同资源状态更新在调用前），按作用域和源码顺序解释。配对关系来自审核元数据，不能从正负标签自动推定有效补丁。共享预算按文本 UTF-8 字节保守计量（可导出计量版本），避免无锁定 tokenizer 时声称精确模型 token 数；后续真实模型实验需冻结 tokenizer。

本轮不做数据迁移、真实标签写回、旧集合重建、付费模型调用或提交发布。对照输出不包含目标真值。
