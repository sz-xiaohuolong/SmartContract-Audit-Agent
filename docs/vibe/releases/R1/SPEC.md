<a id="r1-cli"></a>
## 基础审计与模型网关

Java 21、Spring Boot 4.1.1、Spring AI 2.0.1 的 `audit-mvp` 为默认构建模块。CLI 默认显示帮助，只有显式提供源码、供应商配置及操作后才执行。多供应商通过同一 OpenAI 兼容网关访问；凭证来自环境变量或被 Git 忽略的本地属性文件，报告不保存密钥。

单次旧审计结果与运行状态分开；假设网关使用 schemaVersion=2，最多三项结构化候选。名称、风险操作、绝对行号和来源引用必须绑定目标；拒绝项保留未决，空响应、格式错误、调用故障不能映射为安全。缺失 usage 保留 null，源码与配置身份随报告记录。对应原 S0-01–S0-05、S9-03。

<a id="r1-data"></a>
## 数据、知识与实验记录

源码清单校验字节、项目、事件、补丁对和克隆关系；完全重复及同组变体不得跨知识、开发、验证或锁定测试划分。审核标签与未知标签分开，不能从目录名推断安全真值。锁定集不因工程运行开放。

知识快照包含清单、文档、向量与摘要，完整校验和全量读回后才激活；活动指针切换不修改旧快照。正式案例、待审候选和自动标注知识分别保留准入层级。R1 默认 Nomic 活动快照包含 300 组自动标注改动对、600 条文本、768 维；这些文本不等同于逐案审核的安全修复。

批处理逐项持久化，绑定源码、配置、知识快照和候选池；单写者控制与断点恢复防止重复消费。完成、失败和无法确定是否计费的记录不自动重发；只读重放不调用模型。原 S1、S3、S5 和 S7–S8 的数据契约继续适用。

<a id="r1-retrieval"></a>
## 检索与 D1

检索接收目标事实、绑定和独立候选池，目标真值不进入 Java 检索接口。基础对照支持 Dense、Hybrid、普通正反例和 D1；工作台批量比较 DENSE、FIELD_FILTER、D1，并记录同池身份。

D1 展示漏洞／防御片段、条件绑定、适用性、分数及缺口，过滤不适用支持，减少重复片段和没有新增条件的配对。工作台 D1 上下文最多 4096 UTF-8 字节；字节预算不等于完整提示 token 公平。受限主体、资源、别名、作用域或顺序无法确定时保留 UNKNOWN。对应原 S2、S9-02。

<a id="r1-workbench"></a>
## 单合约审计闭环

| 原验收编号 | 最终行为 | 可观察接缝 |
|---|---|---|
| S9-01 | 预置样本或粘贴 Solidity 可预览；显示合约、函数、调用、状态写入、CEI、源码摘要与解析范围 | 目标纯函数、工作台 HTTP |
| S9-02 | 固定 Nomic 默认快照；展示 D1 配对及 4096 字节预算 | 固定快照和预算回归 |
| S9-03 | 模型假设经 Java schemaVersion=2 严格绑定；保留 usage 空值 | loopback 模型夹具 |
| S9-04 | 模型后执行 Slither，按配置可用 Mythril；保留告警、状态、位置、耗时、版本和失败原因 | 本地子进程夹具 |
| S9-05 | D2 输出 actor、resource、pre_risk_guard、entry_coverage、state_version、bypass 六项三态与证据 | D2 正反例及绑定回归 |
| S9-06 | 六阶段、源码高亮、D1 片段、假设、工具与 D2 矩阵可见；报告下载和历史无需重复调用 | 浏览器交互、JSONL 与历史 HTTP |
| S9-07 | 批量报告同时保留原模型指标、工具、D2 和最终裁决 | 批量结果与页面一致性 |
| S9-08 | Host/Origin、输入大小、严格字段、配置摘要、预览票据及单写者校验；粘贴源码不进入知识或真值 | 拒绝请求、漂移、并发及注入回归 |

工作台先绑定目标、范围、检索、配置和快照，再消费运行票据。模型与工具配置在执行前冻结，凭证只在内存及权限 600 的临时文件中消费，结束后清理。服务重启后未封口运行显示 INTERRUPTED，历史身份校验失败拒绝回放。新报告 schemaVersion=2，旧报告只读。

<a id="r1-batch"></a>
## 批量与计费边界

运行前预览目标、策略、重复次数、端点、模型、快照及请求上界；真实模式由使用者显式选择已有配置。每项保存模型结果、拒绝假设、工具故障、D2 未知、最终裁决和可用 usage，失败与缺失项保留在分母。

原 S6 的预算前置启动限制已按后续明确授权取消；缺少实际 tokenizer、完整输入 token 或费用时保留 null，不能用字节数代替，也不据此宣称科研公平。不同解析、提示或嵌入配置下的历史指标不能直接归因于 D1。

## 判定与不包含的能力

工具运行成功或空告警、模型未提假设、保护名称存在及意见一致均不能证明安全。HYPOTHESES_REFUTED 只反驳已提出候选，NO_CONFIRMED_FINDINGS 只表示没有确证发现；证据不足为 UNKNOWN 或 UNRESOLVED。

R1 程序事实是受限语法提取；继承、分支、别名、跨函数或相关入口无法覆盖时保持未知。真实编译环境、完整路径证明和独立研究先导不属于本阶段已验能力，由 R2 接续。工程验收不证明 D1 增益或 D2 准确率。
