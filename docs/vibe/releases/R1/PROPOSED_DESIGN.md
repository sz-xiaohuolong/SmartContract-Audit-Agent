## 模块与证据流

```text
目标与范围 → 固定事实／快照／同池检索 → Java 结构化假设
           → Slither／可选 Mythril → D2 六义务 → 报告／历史
```

Java 负责模型网关、检索接口和受控工具进程；Python 负责目标、受限程序事实、编排、D2、报告与本机 HTTP。检索策略独立于模型，标签独立于运行输入；数据层记录来源、谱系和快照身份。

配置捕获、模型返回、工具结果、最终裁决各保留独立状态。模型或工具故障仍可保存已获得的证据，完整性不足为未知。源码、配置与池身份在预览和消费之间核对，历史仅做只读校验。

## 范围与恢复

受限语法与绑定只支持可以明确识别的简单路径；不存在继承、别名、分支或跨函数的完整证明承诺。中断保留检查点，不自动重新消费可能已计费的调用；旧报告和知识快照保留只读。
