# OpenZeppelin 展平对照

此目录保存 50 份现有展平合约，与根目录的 SmartBugs、SolidiFI 数据集来源不同。它们从历史资源目录原样移动，旧文件名和 SHA-256 保持不变。

源码中的来源为 `@openzeppelin/contracts`，许可证与各片段版本说明随文件保留。完整生成版本未登记，当前来源与内容身份见 [数据源登记](../../datasets.json)。

当前批量加载器仅选择 `safe_23_Ownable.sol`、`safe_24_Ownable2Step.sol`、`safe_25_AccessControl.sol`、`safe_30_Pausable.sol`；其余文件作为已保存的对照来源保留，不自动扩大实验规模。`safe_` 文件名前缀及阴性标签均不构成安全证明，研究准入保持关闭。
